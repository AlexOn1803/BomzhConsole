# Кишенькова консоль на ESP32-C3

Лаунчер з меню ігор на SD-карті, завантаження ігор по Wi-Fi і дев'ятнадцять ігор: **Бомж-сим, Змійка, Тетріс, 2048, Flappy Bird, Doodle Jump, Загарбники, Lines, Сокобан, Підземелля, Цукерки, Dino Runner, Шашки, Шахи, Тамагочі, Ферма, Космошахтар, Скарби храму, Хрестики-нолики**. Збереження лежать на карті в `/saves`, а запасна копія — у пам'яті плати.

## Що в архіві

| Що | Для чого |
|---|---|
| `README.md` | Ця інструкція |
| `wiring.html` | Повна схема пайки (відкрий у браузері) |
| `firmware/launcher_full_0x0.bin` | Лаунчер одним файлом для прошивки через USB на адресу 0x0 |
| `firmware/launcher_update.bin` | Той самий лаунчер для оновлення по Wi-Fi (без кабелю) |
| `Launcher/` | Код лаунчера (меню + Wi-Fi). Відкривай `Launcher.ino` |
| `GamesMD/` | Код ігор, кожна у своїй папці: Bomzh, Snake, Tetris, Game2048, Flappy, Doodle, Invaders, Lines, Sokoban, Rogue, Candy, Dino, Checkers, Chess, Tamagotchi, Farm, Miner, Temple, TicTac |
| `docs/index.html` | Прошивальник лаунчера з телефона (Chrome + кабель OTG): **https://alexon1803.github.io/BomzhConsole/** |

Кожна папка з кодом самодостатня: файли спільної бібліотеки (`bz_*.cpp/.h`, `BomzhCore.h`) лежать поруч зі скетчем, тож окремо нічого встановлювати не треба, крім LovyanGFX.

## Що перепаяти

| Що | Було | Стало |
|---|---|---|
| RST дисплея | GPIO 3 | **3V3** |
| SD: контакт 2 (CS) | — | GPIO 3 |
| SD: контакт 3 (MOSI) | — | GPIO 6 (разом з SDA дисплея) |
| SD: контакт 4 (VDD) | — | 3V3 |
| SD: контакт 5 (SCK) | — | GPIO 4 (разом з SCL дисплея) |
| SD: контакт 6 (GND) | — | GND |
| SD: контакт 7 (MISO) | — | GPIO 21 |
| Кнопка «Назад» | — | GPIO 8 + GND |
| Звук (за бажанням) | — | п'єзо через 100 Ом на GPIO 2 + GND, або динамік через MOSFET AO3400 (див. `wiring.html`) |

Кнопки: ▲1 ▼0 ◀20 ▶5 OK 9 Назад 8. Карту форматуй у **FAT32** (MBR), найкраще карта 4–32 ГБ. Повна схема пайки — `wiring.html`.

## Перший запуск

1. **Arduino IDE:** плати `esp32` by Espressif (3.x), бібліотека `LovyanGFX` (Library Manager).
2. Відкрий `Launcher/Launcher.ino`. Tools: **ESP32C3 Dev Module**, **USB CDC On Boot: Enabled**, **Flash Mode: DIO**, Flash Size 4MB. Натисни **Upload**.
   Таблиця розділів береться з `Launcher/partitions.csv` автоматично: 1,5 МБ під лаунчер і 2,4 МБ під гру.
3. Скопіюй вміст `sd_card/` на карту, встав її і ввімкни консоль.

Можна без Arduino IDE: проший `firmware/launcher_full_0x0.bin` на адресу **0x0** через веб-прошивальник ESP (наприклад, espressif.github.io/esptool-js) або `esptool.py write_flash 0x0 launcher_full_0x0.bin`.

## Як користуватися

- **Меню:** ▲▼ — вибір, OK — запустити. Перший запуск гри копіює її з карти в пам'ять (5–10 с), наступні — миттєві.
- **Вихід з гри:** затисни «Назад» на 1 секунду → «Вийти». Або тримай «Назад» під час увімкнення.
- **Після вимкнення** консоль відкриває меню. Пункт «Автозапуск останньої гри» вмикає запуск одразу гри.
- **Звук:** пункт «Звук» у меню вмикає й вимикає звук в усіх іграх.
- **Видалити збереження:** у меню ігор затисни «Назад» — відкриється список збережень; можна видалити одне або всі.
- **Прошивка через USB, якщо плата не відповідає:** вимкни вимикач, затисни OK, встав кабель, відпусти OK.

### Завантаження ігор по Wi-Fi
1. У меню вибери «Завантажити ігри по Wi-Fi».
2. Скануй QR на екрані камерою телефона (або мережа `BomzhConsole`, пароль `bomzh2026`).
3. Відкрий у браузері **http://192.168.4.1** — там можна додати `.bin`, видалити ігри, скачати чи видалити збереження.
4. «Назад» — вийти: консоль перезапуститься (~1 с) і відкриє меню, нові ігри вже в списку. Перезапуск потрібен, бо на час Wi-Fi лаунчер віддає мережі частину пам'яті екрана.

Назву, опис та іконку гри лаунчер бере з SD-карти, тож нову гру видно в меню одразу, без перепрошивки лаунчера. Поклади поруч з `назва.bin` файл `назва.txt` (UTF-8):

```
Змійка
Їж яблука, не врізайся в стіни
колір=4cd964
BM(IC_SNAKE, "..........", ".######...", ".#....#...", ".#.##.#...", "...#..#...", "...#..###.", "...#....#.", "...####.#.", "........#.", "......###.");
```

Рядок 1 — назва, рядок 2 — опис, `колір=` — колір іконки (необов'язково), далі іконка: `#` — точка, `.` — порожньо, до 16×16. Рядки іконки можна писати в лапках, як вище, або просто по одному в рядку без лапок.

### Оновлення прошивки по Wi-Fi
1. Увійди в «Завантажити ігри по Wi-Fi» й відкрий **http://192.168.4.1**.
2. Унизу сторінки, у розділі «Прошивка консолі», вибери `launcher_update.bin` (або свій `Launcher.ino.bin` з **Sketch → Export Compiled Binary**; файл `merged` не підходить).
3. Консоль перевірить файл (гру замість прошивки вона не прийме) і напише «Прошивка отримана — натисни OK». Натисни OK.
4. Оновлення йде у два етапи, близько 20 с. Не вимикай консоль. Якщо живлення таки зникне, консоль запуститься з запасної копії й повторить.

Файл можна й просто покласти на карту як `/firmware/launcher.bin` — у меню з'явиться пункт «Оновити прошивку консолі». Після оновлення першу гру треба буде встановити заново (5–10 с).

## Своя гра

1. Скопіюй папку будь-якої гри з `GamesMD/` як заготовку (у ній уже є файли бібліотеки), підключи `#include "BomzhCore.h"`, у `setup()` виклич `consoleBegin("назва")`, у `loop()` — `consolePoll()` та `inputGet()`.
2. Малюй у `gfx::fb` (240×320) і виклич `present()`. Рекорди — `saveData()` / `loadData()`.
3. Довге «Назад» (`K_BACK_LONG`) → `if (confirmExit()) returnToLauncher();`.
4. **Sketch → Export Compiled Binary**, поклади `.bin` на карту в `/games` (або через Wi-Fi), а поруч `.txt` з назвою, описом та іконкою. Кнопкою Upload гри не заливай — це зітре лаунчер.

Порада: код гри тримай у `main.cpp`, а `.ino` залиш порожнім — так Arduino IDE не плутається з кирилицею й класами.
